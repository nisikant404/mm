## Milestone v1.1 Requirements

### Symptom Chatbot Interface
- [x] **CHK-01**: Implement a chatbot interface where the user can input symptoms free-text. (Validated)
- [x] **CHK-02**: The AI backend processes the inputs, asks follow-up questions if necessary, and determines the probable medical issue and the exact doctor specialization domain. (Validated)

### Dynamic Doctor Listing
- [x] **DOC-01**: Based on the diagnosed domain, display a dynamic side-list of available doctors matching that specialization. (Validated)
- [x] **DOC-02**: Display each doctor's professional experience and relevant credentials neatly within the side-list. (Validated)

### Appointment Booking
- [x] **APT-01**: Integrate a "Book Appointment" button for each listed doctor that raises an appointment ticket/record in the patient's database. (Validated)
